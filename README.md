## 📖 Overview

High-concurrency real-time video conferencing platform built with Python Flask, Socket.IO signaling, WebRTC peer-to-peer media mesh, and persistent meeting database.

## 🚀 Deployment & Environment

> 💻 **Deployment Mode:** `Local / Server Mesh: http://localhost:5000`  
> Fully configured for local development, containerized environments, and enterprise private cloud orchestration.


---

## ✨ Key Features

- **Ultra-low-latency HD audio/video streaming via native WebRTC peer-to-peer mesh**
- **Dynamic room orchestration with instant invite code generation and passkeys**
- **In-meeting text chat and live participant roster with mute/camera toggle controls**
- **Automated camera/microphone permission detection and fallback media handling**
- **Relational database integration for scheduled meetings and authenticated user profiles**

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18.0.0 or higher) / Python 3.10+ (where applicable)
- Git installed on your system

### Installation & Run

```bash
git clone https://github.com/M20A03/OnlineMeetingApp.git
cd OnlineMeetingApp
pip install -r requirements.txt # or install flask flask-socketio
python database.py # initialize database
python test_conn.py
```
